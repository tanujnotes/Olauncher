# Elauncher

Elauncher is a personal fork of [Olauncher](https://github.com/tanujnotes/Olauncher)
by tanujnotes, licensed GPLv3. It keeps Olauncher's minimal, distraction-free
approach to a home screen and builds on it with a few things I wanted for my own
daily use.

### What's added on top of Olauncher

- **Multiple home pages** — add, remove, rename and reorder pages from Settings.
- **A real widget grid** — place Android app widgets on the home screen, move
  and resize them freely on a visible grid.
- **App List widget** — the home-screen app shortcuts are now a widget: pick
  1-8 apps, rename any of them, and set their alignment independently of
  everything else on the page.
- **Clock and Date & Screen Time as separate widgets** — add either one only
  where you want it, each with its own alignment; the date widget can show
  screen time and links to the usage-access permission if it's missing.
- **App-wide custom fonts** — pick a `.ttf`/`.otf` file from storage and apply
  it everywhere, or just switch on bold.
- **Adjustable background transparency** — a single opacity setting for how
  much of your wallpaper shows through Settings, the app drawer and the pages
  screen, from fully see-through to a solid black/white background.
- **A manual "reduce animations" option** — for e-ink or slow-refresh
  displays the automatic detection doesn't catch.

### Install

For now, Elauncher is only released on GitHub — grab the
[latest APK](https://github.com/vinceumo/Elauncher/releases). It isn't on
F-Droid or the Play Store.

- To maintain the simplicity of the launcher, a few niche features are available but hidden.
